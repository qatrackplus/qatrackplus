Appendix: every poe task
========================

This table is generated when the documentation is built, from the ``help``
line of each task in ``poe_tasks/*.toml``, so it cannot drift from the tasks
themselves; ``poe`` with no arguments prints the same list. The tasks you need
day to day are the six in :ref:`the task runner <task-runner-poe>`. A help
line that begins **WIP** marks a task that is unverified and not part of the
ordinary workflow. Internal helpers (names beginning with ``_``) are omitted.
